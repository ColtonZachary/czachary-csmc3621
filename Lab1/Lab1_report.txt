Lab1_Q2:
    Time and Space complexity
    Time: O(n) 
    Space: O(n) 

    Test 1-
        input:  
            ")(", 
            "((())", 
            "()", 
            "(a)((b)((c)(d)))"
        Results:
            String: )( -> INVALID
            String: ((()) -> INVALID
            String: () -> VALID
            String: (a)((b)((c)(d))) -> VALID
    Test 2 -
        input:
            "()", 
            "(())", 
            "(()())", 
            "((a+b)*(c-d))", 
            "()()()()", 
            "(a(b(c)d)e)", 
            ")(", 
            "((())", 
            "())", 
            "((a+b)*c", 
            "((())())("
        results: 
            String: () -> VALID
            String: (()) -> VALID
            String: (()()) -> VALID
            String: ((a+b)*(c-d)) -> VALID
            String: ()()()() -> VALID
            String: (a(b(c)d)e) -> VALID
            String: )( -> INVALID
            String: ((()) -> INVALID
            String: ()) -> INVALID
            String: ((a+b)*c -> INVALID
            String: ((())())( -> INVALID
